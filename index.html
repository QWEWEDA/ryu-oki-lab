训练场练法

先学会两套，才能真正做到实战使用

01 / 固定压制与反应

  1. 木桩：起身随机防御、4F 小技、起身 OD 无敌技
  2. 角色：隆，版边，按收尾技测试
  3. 先测试 623HP → 空挥 5MK → 5MP
  4. 确认按出招、持续帧、防御优势与距离
  5. 成功 8/10 次再带到对战

02 / 打投与诱拆

  1. 木桩录制起身防御、轻拳抢招、延迟拆投
  2. 随机播放，不要只打静止木桩
  3. 同一击倒先练「投」，再练「打击」
  4. 看到对方爱拆投，再加入后退 Shimmy
  5. 中升龙 5MK 空挥路线务必核对投距

03 / 命中后续连段

  1. 同一起手分别测无 Drive 与 SA3 版
  2. 打开伤害、输入与帧数显示
  3. 区分普通命中、Counter、Punish Counter
  4. 看清是否需要电刃、贴身、版边
  5. 将真正成立的伤害填进自己的训练笔记

04 / 版本更新后

  1. 检查招式发生、持续、硬直、击退距离
  2. 测试原地／后方受身与不同体型
  3. 随机设置起身 4F、投、OD 无敌、DI
  4. 对伤害和连段补正重新记录
  5. 核实后再把“待验证”改为“已验证”
